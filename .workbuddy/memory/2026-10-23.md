## pic-to-pindou 产品立项：图片转拼豆图纸（grill 第 1 轮）

- 仓库仍是 0 commit 的空仓库，无 `GLOSSARY.md` / `docs/adr/`，无历史约束。
- 走 `/grill-with-docs`（grilling + domain-modeling），用户要求的顺序：拼豆细节 → 需求 → 技术栈 → 架构。
- **调研到的领域事实（可复用，别重复查）**：
  - 三种豆规格：迷你 2.6mm（Hama 为 2.5mm）/ 标准 midi 5mm / 大号 10mm。**每颗豆占一根插钉**，所以成品边长 = 颗数 × 豆直径；同一张图纸在三种规格下**网格数据完全通用**，只是物理尺寸变（架构好消息：网格模型与豆规格解耦）。
  - 拼豆板主流是 29×29 插钉大方板，可拼接；5mm 豆摆满一块 = 14.5cm 见方 / 841 颗；58×58（4 块拼接）= 29cm / 3364 颗。圆形 29 孔板做徽章。
  - 色卡：Artkal S 系列（5mm 硬豆）S01–S159 共 159 色，2023 增 SE01–SE15 扩展（部分站列到 SE16/17，bitbead 记 176 色）；Artkal C = 2.6mm 迷你。Hama 用 H01–H104+，Perler 用 80-19xxx 货号。**跨品牌同色不同号，且没有权威公开的统一映射表**。
  - 竞品：`beadifier`（GitHub maxcleme，开源）、`pindou.art`（291 色 + 多品牌映射）、`bitbead.app`（多品牌色板页）、`pixel-beads.org`（起步色板 36 色）、`makebead.com`（尺寸计算器）、`myblockstudio.com`（三品牌色号对照表）。
- 术语纠偏记下：「拼豆图」有歧义，需拆成 **图纸 pattern**（带网格与色号、可照着施工）与 **预览 preview**（模拟成品外观）。

### 技术决策（我定的，用户未反对）

- 色差用 **CIEDE2000（LAB）**，不用 RGB 欧氏距离。
- 缩放：面积平均为主，源图尺寸接近目标网格整数倍时切最近邻。
- 网格 `Uint16Array`，`0` = 空白格，`i+1` = 色卡索引；撤销用网格快照（80KB/步 × 50 步 = 4MB）。
- 手改**直接写网格**，不建 overlay 层（因为重算覆盖语义下 overlay 无存在理由）。
- 渲染按格宽切换：≥6px 豆模板 `drawImage`，<6px 转 `ImageData` 一次性 `putImageData`。
- 量化用 **k-medoids 在色卡内选 K 色**（按像素计数加权），不用 k-means 后吸附（会撞号 + 误差放大）。
- Worker 协议用 `requestId` 单调递增丢弃过期结果，不做队列。
