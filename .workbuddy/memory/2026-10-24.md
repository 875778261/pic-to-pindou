## #2 色卡数据源核查（结论推翻前一日推断）

### 官方 S 系列色卡源已找到并可结构化提取

- 官方页面 `https://artkalfusebeads.com/pages/s-color-chart` 挂着两个 CDN 资源：
  - `https://cdn.shopify.com/s/files/1/1323/8195/files/S_MIDI_Beads_RGB_Color_Chart_2024.pdf`（**含逐色数值 RGB**，矢量 PDF）
  - `https://cdn.shopify.com/s/files/1/1323/8195/files/artkal_beads_S_series_color_chart_2024.jpg`（色卡图，只有色号无名称）
- 该 PDF 每格是 `r g b rg` + `re f*` 矢量色块，旁边印 `色号 / R / G / B` 三列数字，可用 pymupdf 确定性提取，**不需要像素采样**。
- 覆盖：**S01–S159 连续无缺 + SE01–SE17**，共 176 条；编号唯一，RGB 无越界。
- 内部交叉校验：172 个矢量色块的填充色与同格文本 RGB **逐一完全一致**（S01 无色块、S41/S42/S63 无矢量色块）。
- **S41 Gold / S42 Silver / S63 Copper 官方不公布数值**（PDF 该格只印名称）。

### 前一日关于 bitbead 数据的判断是错的，已推翻

- `S18 = S94 = #EAA794`、`S82 = S155 = #C58B68`：**官方同样重复**，不是数据错误。
- bitbead HEX 与官方 RGB 在 169 个可比色号上**全部一致**；唯一无法核对的正是 3 个金属色。
- 真实问题只剩一个：3 个金属色的**名称**在第三方之间错位（官方 S41=Gold、S63=Copper；bitbead 写成 S41=Copper、S63=Metallic Gold）。
- 结论：bitbead 的 HEX 可信度远高于原判断，坑不在色值而在「名称无官方来源」。

- 用户指定的数据源。**不含 Artkal S 系列**：只有 artkal-c-197、artkal-m-221、c197+m221-418 合并版、mard-221/291、coco-291、manman-278、panpan-289、mixiaowo-290、youken-public-174。

- 它自己也记录了同类坑：C197 的 CG/CP/CT 特殊材质官方 RGB PDF 未发布数值，靠官方色卡图采样补齐并标注 quality。

## 用户改口径：色卡改为 MARD 221 + 291

用户提供了落库文件 `docs/MARD 221 拼豆标准色卡对照表 & 291全系速查查询 - 我了个豆.html`（含 `_files/` 伴生目录），明确「使用里面的两套色卡」。**Artkal S 159 方案作废。**
- 数据实际在 `_files/mard-colors-data.js.下载`：`window.MARD_COLORS_DATA = { mard221: [...], mard291: [...] }`，每项只有 `code / name / hex`，**`name` 与 `code` 完全相同**，即这套数据没有色名。
- mard221 = 221 条、mard291 = 291 条，各自 code 唯一、hex 全部合法 6 位。
- **mard221 ⊂ mard291 完全成立**（221 条 HEX 全等，291 多出 70 条，多为 P/ZG/YG 等特种系列）。所以「两套色卡」是同一体系的色域档位，不是两套不同品牌。
- 系列语义（页面上标注）：A 黄橙、B 红粉、C 蓝青、D 绿色、E 紫色、F 棕咖、G 黑白灰、H 荧光、M 过渡；291 另有 ZG 珠光、YG 夜光等。
- 与 HansBug 仓库交叉比对（同色号逐值）：
  - user221 vs `mard-221-alfonse-doudou`：221 中仅 2 个一致，219 个不同
  - user221 vs `mard-221-github`：仅 4 个一致
  - user291 vs `mard-291-github`：仅 17 个一致
  - 而 HansBug 自己两个 MARD 221 源之间也差 77 个
  - 差异幅度多为 2–8/255，属「同色不同工具显示近似值」
- 结论：**MARD 系列不存在官方 RGB**，各家公开数据互不相同。这与 Artkal S 有官方 PDF 数值的情况相反 —— 色号用于下单仍然可靠，但色值的权威性无法像 Artkal 那样自证。
- 影响：ADR-0001（只做 Artkal S 159）、spec 的「色卡」技术决策、issue #2 验收②③ 都需要改，属范围变更，需先落文档再编码。
