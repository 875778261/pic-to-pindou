## #6 背景空白色：实现完成，等验收

**两个口径决策（用户当场敲定）**：匹配粒度＝**色号**（不是量化前的源图颜色）；点选位置＝**现有预览画布**（不新增源图视图）。

- 动因：源图颜色在采样后逐格带噪。白底 ±3 噪声的 290² 测试图，621 个白底格有 4 种数值，逐格精确相等只命中 365 格，剩下 256 格（41%）照样长成白豆 —— 「白底不再长出一圈白豆」做不到。
- 管线改为**两遍量化**（`convert.ts`）：第一遍不排除任何色号，认出「哪些格是那个色号的豆」（所见即所抹）；第二遍把空白色号排出候选集、把这些格排除出选色权重，腾出的名额回到剩下的画面。没有空白色 / 标的色号在图上不存在时只跑一遍，性能与从前一致。
- `params.blankColours`（hex）→ `params.blankCodes`（`BeadCode[]`）。`selectMedoids` 加第 4 参 `excludedCodes`；`mapColoursWithDither` 加 `blankMask`（空白格不扩散也不接误差）。
- UI：`PreviewStage` 画布可点（格坐标 = 点击位置 ÷ 显示尺寸 × 格数）→ `paletteEntryForCell` 得色号 → `store.markBlank`；新组件 `BlankCodes.tsx` 列出已标色号、每个可撤；`ParameterPanel` 加「空白色号」小节。
- store 抽 `commitParams()`：`updateParams` / `markBlank` / `unmarkBlank` 共用「换参数 + 请重算」，不再三处复写。
- ADR-0010 落档（含实测表、「量化前排除 vs 量化后改写」的选项对比、与 spec 手势一节为何不冲突、重选色号可能让个别格改邻色的已知边界）。GLOSSARY 加「空白色号」；spec 与 plan 的 `blankColours` 表述同步。
- 测试 133 绿（127 → 133，convert 从 13 到 19：相邻不连带、照片状白底、不占 K、多色号同标、抖动下留空、未知色号无副作用）。`tsc -b` / `biome check .` / `vite build` 干净。
