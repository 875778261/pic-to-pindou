# 特种色不进量化候选

291 档比 221 档多出的 70 个色号是特种色：`ZG` 珠光、`Y` 夜光、`P`/`R`/`Q`/`T` 特种系列。
它们的屏幕色不反映实物——珠光随角度变色、夜光在暗处发光、半透明会透出板钉颜色。
把这些色号交给量化算法选色，会大量产出「色号没错但买回来对不上」的结果，而且这些色号线下经常缺货。

因此：特种色照收进色卡并打 `material: 'special'` 标，图例与预览上可区分，但**不参与量化选色**；
用户手改时仍可选用——那是用户明确的选择，不是算法替他决定的。

**Status**: accepted

**Considered Options**：
- 特种色与标准色同等参与量化（否决——屏幕色与实物偏差最大的一批色号，恰恰会被算法优先选中）
- 把特种色排除出色卡（否决——291 档就退化成 221 档，两档失去意义）

**Consequences**：量化候选集在 291 档下实际是 221 个标准色。用户若想用珠光豆，只能手改。
将来做珠光/夜光的光学模拟（不在当前范围）要重新审视这条。
