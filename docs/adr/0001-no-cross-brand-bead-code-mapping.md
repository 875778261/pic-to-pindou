# 不做跨品牌色号映射

Perler、Hama、Artkal 各有独立的色号体系，同一颗颜色在三家品牌下是不同的编号。多个拼豆工具提供「一键换品牌」的转换，我们**不做**。原因是公共渠道不存在可验证的权威色号对照表——现有各站的映射表都是自行维护的，无法核对。映射错的后果由用户承担：他按图纸下单，买回来的豆色不对。

只做 Artkal S 系列 159 色。想用 Hama 或 Perler 的人需要自己换算，这一点在界面上明说。

**考虑过的替代**：接入第三方整理的多品牌对照表（否决——不可验证，错在用户身上）；同时维护三套色卡但不做映射（留待将来，只是数据量问题，不含推断风险）。

**后果**：将来若要支持映射，前提是先拿到官方或可交叉验证的对照来源，而不是先写代码。
