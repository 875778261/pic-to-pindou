# 预览渲染按格宽切换画法

格宽 ≥ 6px 时，用离屏单豆模板逐格 `drawImage` 铺出立体豆子；格宽 < 6px 时，把网格直接转成 `ImageData` 一次性 `putImageData` 输出扁平色块。

网格上限是 200×200，即 40000 格。缩放到适应窗口时格宽只有 2px 左右，此时逐格绘制 40000 个圆每帧都会掉帧，而 2px 下豆孔与缝隙根本分辨不出来——画了也白画。切换阈值取 6px 是豆形开始可辨的下限。

**后果**：所谓「豆子模拟 / 扁平色块」两种风格并不是两个独立功能，小尺寸下的扁平是唯一合理画法，用户的手动切换只在大格宽时生效。两套画法必须共用同一套坐标变换与裁剪逻辑，否则跨过 6px 阈值时画面会跳。
