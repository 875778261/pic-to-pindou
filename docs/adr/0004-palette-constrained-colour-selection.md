# 量化在色卡内部选色，而非聚类后吸附

先按像素分布选出不超过 K 个色号（k-medoids，候选集就是那 159 个色号，按各颜色的像素数加权），再把每一格映射到选中集合里最近的一个。**不采用**「k-means 聚类后把簇心吸附到最近色号」的常见做法。

后者有两个实际问题：两个簇心可能吸附到同一个色号，导致实际用色数少于用户设的 K，白白浪费预算；簇心落在色卡之外时，吸附误差被放大两次。前者天然保证「用色数 ≤ K」且「每一种都真实存在」。

**考虑过的替代**：k-means + 最近色号吸附（否决，理由同上）；不限色逐格取全色卡最近色（否决，会用到上百个色号，采购成本失控）。

**后果**：需要一份 159×159 的色差矩阵和加权迭代，几十毫秒量级，可接受。若将来接入 300+ 色的完整色卡，矩阵会涨到九万项，仍在可接受范围内。
