### 05 作品介绍（必填，≥30 字，≤2000 字）

**主版（推荐，约 600 字）**

```text
「拼豆图纸生成器」把一张普通图片变成可以照着摆的拼豆施工图：定网格尺寸、限色号数量、点掉不想摆的颜色，屏幕上立刻出现模拟成品的预览；看顺眼了导出一张 PNG——网格线、行列坐标、每格色号、成品尺寸、总颗数，以及按颗数降序排列的配色清单都在上面，照着摆就行。

【给谁用】
玩拼豆的人。想摆一张自定义图案，却卡在「先画图纸」这一步：网格定多大、用哪几个色号、每个色号要买多少颗，全靠肉眼对色和计算器。网上的工具要么只把图变像素、不给色号，要么全英文、手机上没法用。结果是想做拼豆的人还没开始摆就先累完了。

【核心功能】
1. 尺寸按「几块 29×29 拼豆板」直接选（1 块、2 块、4 块、9 块），也能自己填宽高；成品多少厘米见方、总共多少颗，边调边实时算出来。
2. 色卡用 MARD，分 221 标准档与 291 全系档；色号上限自己定，实际用掉几个色实时显示。色号即名称，不给编造的色名。
3. 白底照片最容易长出一圈白豆——在预览上点一下那颗豆，整个色号一次性标成「不摆豆」，而且不占色号名额。
4. 预览用豆形画法，看得见豆身、中心孔和豆间缝隙，判断的是成品观感而不是像素图；也能切扁平色块看轮廓。支持缩放平移、一键适应窗口、以鼠标位置为中心缩放。
5. 个别格子配得不准，可以进编辑态直接涂色，带橡皮掏洞和撤销重做；一次拖动算一步撤销，涂色时不会因为想平移画布而误涂一片。
6. 导出的是施工图而不是效果图：格数不多时每格中心标色号，格数太多时自动只留坐标加图例，不会糊成一团；空白格与白色豆在图上画法不同，不会在该空的地方塞白豆。
7. 图片不上传服务器：解码、量化、导出全在浏览器本地完成，不需要登录、不需要后端。

【体验方式】
直接打开链接，把图片拖进页面（或从相册选择），挑一个尺寸预设，几秒内出结果；不满意就拉亮度、对比度、饱和度滑块，或换色号上限再试。手边没图可以随手拍一张。

【技术说明】
React 19 + TypeScript + Vite，纯静态部署在 Cloudflare Workers；颜色量化跑在 Web Worker 里，拖滑块时主线程不卡；12 个测试文件、177 个单元测试覆盖量化、裁切、图例排版与撤销逻辑。
```

**精简版（若想更短，约 180 字）**

「拼豆图纸生成器」把任意图片变成可以照着摆的拼豆施工图。定网格、限色号、点掉不摆的颜色，屏幕上实时预览；满意后导出 PNG——带网格线、行列坐标、每格色号、成品尺寸、总颗数和按颗数排序的配色清单，照着摆就行。

### 06 作品体验链接（必填）⚠️

当前候选：

```text
https://pic-to-pindou.875778261.workers.dev
```

**这一项先别提交**，有两个硬问题：

1. **表单明确要求链接带有效 `sharecode` 参数**。`workers.dev` 是自部署地址，没有 sharecode。表单的前端校验只查 `http(s)://`，所以能提交上去，但人工审核时「缺少 sharecode」是被写进提示语里的扣分项。
2. **国内大概率打不开**。我在这台机器上实测：`workers.dev` 被解析到 `128.121.243.107` / `2a03:2880:f10d:…`（典型污染 IP），`curl` 直接连不上，浏览器也取不到页面。你自己的部署方案文档里也写过「`*.workers.dev` 在国内经常被 DNS 污染，直连不稳」。

**建议的处理顺序：**

- **A（推荐）** 用 WorkBuddy 客户端把项目**「发布为应用」**，拿那条 `workbuddy.link` 链接（带 sharecode）。这条链接既满足表单要求，也走的是活动方自己的域名，评审一定能打开。取法：WorkBuddy 对话里点发布 → 复制链接；或「设置 → 数据管理 → 应用」里取。
- **B（备选）** 给 Workers 绑一个**自有域名**（Cloudflare Custom Domain），把 `workers.dev` 换掉。能解决污染，但仍绕境外线路，且依然没有 sharecode。
- **C（兜底）** 两条都填不了，就填 Workers 地址，并在 05 作品介绍末尾加一句「如链接无法打开，可访问备用地址」，备用地址同样要能打开。

> 提交前务必**换一台设备 / 换手机流量**重新打开一次完整链接，确认不登录、不需要密码就能玩。
