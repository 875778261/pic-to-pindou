# Triage 标签

各技能用五个标准 triage 角色来描述状态。本文件把这些角色映射到本仓库 issue 追踪器里实际使用的标签字符串。

| mattpocock/skills 中的标签 | 本仓库追踪器中的标签 | 含义                         |
| -------------------------- | -------------------- | ---------------------------- |
| `needs-triage`             | `needs-triage`       | 待维护者评估该 issue         |
| `needs-info`               | `needs-info`         | 等待报告者补充信息           |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整，可交给 AFK agent   |
| `ready-for-human`          | `ready-for-human`    | 需要人工实现                 |
| `wontfix`                  | `wontfix`            | 不做处理                     |

五个标签均已在仓库创建：`wontfix` 沿用 GitHub 默认标签，其余四个为新建，颜色见 `issue-tracker.md` 的 `## Triage 标签` 段。

当某个技能提到某个角色（例如「打上 AFK-ready 的 triage 标签」），就使用本表中对应的标签字符串。

若你的追踪器用了别的命名，改「本仓库追踪器中的标签」这一列即可。
